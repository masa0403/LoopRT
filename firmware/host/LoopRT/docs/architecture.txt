========================================
LoopRT Architecture
Version: v0.1
========================================


## Overview

LoopRTはRuntimeを中心として、
Experimentを実行する組み込み向けランタイム。

現在は起動時に1回だけExperimentを実行する。


## System Flow

Boot

↓

Runtime

↓

Executor

↓

Experiment

↓

Program

↓

CommandReader

↓

Command

↓

Command.execute()



## Component Structure


Runtime
 |
 |-- Flash
 |
 |-- Executor
 |
 |-- Experiment
        |
        |-- Program
              |
              |-- CommandReader
                    |
                    |-- Command



## Component Responsibilities


----------------------------------------
Runtime
----------------------------------------

LoopRT全体の管理を担当。

責務:
- 初期化
- 実行開始
- 終了処理

所有:
- Flash
- Experiment
- Executor



----------------------------------------
Flash
----------------------------------------

Flash領域へのアクセスを担当。

現在:
初期化と書き込みインターフェースのみ存在。



----------------------------------------
Executor
----------------------------------------

Experimentの実行制御を担当。

責務:
- Experiment呼び出し
- 実行開始/終了管理



----------------------------------------
Experiment
----------------------------------------

1つの実験単位を管理。

責務:
- Program実行管理



========================================
Program
========================================

変更:

execute()

while (true)
    ↓
CommandReader.read()
    ↓
Command取得
    ↓
Command.execute()
    ↓
終了命令なら終了
    ↓
Command削除

現在:
複数Commandを順番に実行可能になった。

未実装:
- Program Counter
- Flash読込
- 実Command実行



----------------------------------------
CommandReader
----------------------------------------

Command取得を担当。

現在:
固定Commandを生成する。


========================================
Command Execution
========================================

現在の実行経路:

Runtime
↓
Executor
↓
Experiment
↓
Program
↓
CommandReader
↓
Command
↓
Arduino GPIO

Commandの実行:
- PinHigh: Arduino D13をHIGH
- PinLow: Arduino D13をLOW
- Delay: 1000ms待機
- End: Program終了

現在:
Commandが実際のArduinoハードウェアを操作可能。

First Hardware Execution:
Arduino Nano D13 onboard LEDによるGPIO動作確認済み。

========================================
External Command Input
========================================

現在:

Python
↓
Serial
↓
CommandReader
↓
Program
↓
Command
↓
Arduino Hardware

CommandReader:
- Serialから1文字のCommandを受信
- H = PinHigh
- D = Delay
- L = PinLow
- E = End
- CR/LFは無視

現在:
PythonからLoopRTへCommandを送信し、
Arduino NanoのD13を実機操作できる。

確認済み:
Python → Nano D13 LED ON/OFF
