# LoopRT 実験プロジェクト開発ルール

あなたは組み込み開発AIです。

これから、**LoopRTを使用してATtiny202向けの小さな組み込みプロジェクトを設計・実装し、実機で検証してください。**

---

# 1. 開発環境

以下の構成で実験します。

* Target MCU：ATtiny202
* Host MCU：Arduino Nano
* Host MCUではLoopRTが動作している
* PCからPythonを使用してLoopRTへコマンドを送信する
* Target MCUには、あなたが作成したCコードをFlashする
* Target MCUとHost MCUは抵抗を介して接続されている
* LoopRT本体はすでに動作確認済み

## 重要

今回、**LoopRT本体のコードは変更しないでください。**

あなたが作成・変更するものは基本的に以下の2つです。

* Target MCU用Cコード
* LoopRTへ送信する検証用commands

---

# 2. PinConfig（物理配線）

現在の物理配線は固定されています。

| Target MCU    | Host MCU        | 用途            |
| ------------- | --------------- | ------------- |
| ATtiny202 PA2 | Arduino Nano D7 | PWM観測         |
| ATtiny202 PA3 | Arduino Nano D8 | GPIO / 信号入力   |
| ATtiny202 PA6 | Arduino Nano D9 | RC回路を介したADC入力 |

つまり、

```text
Target PA2 ↔ Host D7
Target PA3 ↔ Host D8
Target PA6 ↔ Host D9
```

です。

## 絶対に注意すること

Target MCUのコードでは、

* PA2
* PA3
* PA6

という**ATtiny202側のピン番号**を使用します。

一方、LoopRTのcommandsでは、

* D7
* D8
* D9

という**Arduino Nano側のピン番号**を指定します。

Target MCUとHost MCUのピン番号を混同しないでください。

---

# 3. PA6-D9間のRC回路

TargetMCUにADC機能を実装する必場合、**PA6-D9間の既存RC回路を使用してください。**

信号経路は以下です。

```text
Arduino Nano D9
      │
      │ PWM
      ▼
    RC回路
      │
      ▼
ATtiny202 PA6
      │
      │ ADC
      ▼
   ADCで電圧測定
```

現在のRC回路は、

```text
R = 3.3 kΩ
C = 3.3 μF
```

です。

RC回路によってHost D9から出力されたPWMを平滑化し、Target PA6へアナログ電圧として入力します。

PA6をTarget MCU側のPWM出力として使用する設計にはしないでください。

---

# 4. LoopRTで使用できるcommands

現在使用できるLoopRT commandsは以下です。

```text
H(pin)       GPIO HIGH
L(pin)       GPIO LOW

I(pin)       GPIO input observe

P(pin,value) PWM output
PI(pin)      PWM input observe

D(value)     Delay

E            End
```

---

# 4.1 GPIO HIGH

```text
H(8)
```

Arduino NanoのD8をHIGHにします。

これはTarget MCUのPA3へHIGH信号を入力するために使用できます。

---

# 4.2 GPIO LOW

```text
L(8)
```

Arduino NanoのD8をLOWにします。

これはTarget MCUのPA3へLOW信号を入力するために使用できます。

---

# 4.3 GPIO Input Observe

```text
I(7)
```

Arduino NanoのD7の**現在のGPIO状態**を読み取ります。

結果は、

```text
[OBSERVE] D7 HIGH
```

または、

```text
[OBSERVE] D7 LOW
```

のように出力されます。

## I()の重要な仕様

`I(pin)` は、**その瞬間のGPIO状態を1回読み取るだけ**のコマンドです。

LoopRTは、

* 前回の状態を保持しない
* 状態遷移を管理しない
* HIGHエッジを検出しない
* LOWエッジを検出しない
* 自動的に別のGPIOを操作しない

という設計です。

必要な状態判定は、AIが検証commandsを設計する際に行ってください。

例えば、出力操作によって別のピンの状態が変化することを確認したい場合は、

```text
I(7)
H(8)
I(7)
L(8)
I(7)
```

のように、**出力操作の前後でI()を使用して状態を確認してください。**

つまり、

```text
I() = 現在値の観測
```

です。

状態遷移の解釈や、前後の状態比較はAI側で行ってください。

---

# 4.4 PWM Output

```text
P(9,50)
```

Arduino NanoのD9から50% PWMを出力します。

**これはTarget MCUのPWM出力ではありません。**

LoopRTを実行しているHost MCU、つまりArduino NanoのD9からPWMを出力します。

今回の実験では、

```text
Host D9
 ↓
RC回路
 ↓
Target PA6
```

という入力信号を作るために使用してください。

---

# 4.5 PWM Input Observe

```text
PI(7)
```

Arduino NanoのD7に入力されたPWM信号を観測します。

Target MCUのPA2から出力されたPWMをD7で観測するために使用します。

LoopRTはPWMを一定時間観測し、例えば以下のような情報を取得できます。

```text
[TARGET] Duty Avg: 49.xx %
[TARGET] Period Avg: xxxx us
[TARGET] Frequency Avg: xxx.xx Hz
```

`PI()` はPWM信号の測定用です。

一方、`I()` はGPIOの現在値を1回読むためのものです。

この2つを混同しないでください。

---

# 4.6 Delay

```text
D(500)
```

500ms待機します。

Target MCUのADC値が安定する時間や、PWM出力が安定する時間を確保するために使用してください。

---

# 4.7 End

```text
E
```

実験を終了します。

---

# 5. commandsの重要な考え方

commandsは、Target MCUのCコードを直接操作するものではありません。

commandsは、

* Host MCUからTarget MCUへ入力信号を与える
* Target MCUからHost MCUへ出力された信号を観測する

ための**実験手順**です。

例えば今回、

```text
Host D9
 ↓
RC回路
 ↓
Target PA6
 ↓
ADC
```

という入力経路を使用します。

そのため、

```text
P(9,25)
```

は、

**Host D9から25% PWMをTarget PA6へ入力する**

という意味になります。

一方、

```text
PI(7)
```

は、

**Target PA2から出力されたPWMをHost D7で観測する**

という意味になります。

また、

```text
I(7)
```

は、

**その瞬間のHost D7のGPIO状態を読み取る**

という意味になります。

# 6. 今回作るプロジェクト

今回のプロジェクトは、

**「PA3HIGH立ち上がりエッジでPA2をON,OFFスイッチング。その際、10秒間のFade-In,Fade-OUTでスイッチングする」**

としてください。

できるだけシンプルにしてください。

基本的な処理は以下です。

```text
Host D8
  │
  ▼
  LOW→HIGH→LOW（0.5秒程度だけHIGHする。これがスイッチング入力）
  │
  ▼
Target PA3
  │
  ▼
Target PA2
  │
  ▼
  PWM(Fade-IN / Fade-OUT)　＊Fade-INしたらその後はずっとDuty100％。
  │
  ▼
Host D7
  │
  ▼
LoopRTでPWM観測
```

実装時に注意するポイント
・Fade処理実行中はスイッチングの入力を無視する
・LEDのFadein→常時HIGH→Fadeoutは途切れずなめらかな挙動を実現する。デバッグもそのあたりを細かくチェックすべし
